# test/specs-sample

Снимки официальных OpenAPI-спек Wildberries, скачанные с
`https://dev.wildberries.ru/api/swagger/yaml/ru/` и используемые как фикстуры
интеграционных тестов (`test/mcp.test.mjs`). Полные спеки в репозиторий не
коммитятся — их скачивает `sync.mjs` при установке.

Источник и права: документация Wildberries Seller API (публичная).
